# Email Spam Classifier

## Overview
This project uses Machine Learning and Natural Language Processing (NLP) to classify messages as Spam or Ham (Normal).

## Features
- Spam Detection
- Ham Detection
- TF-IDF Vectorization
- Naive Bayes Classification
- Streamlit Web Interface

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Joblib

## Model Accuracy
96.23%

## How to Run

1. Install dependencies

pip install -r requirements.txt

2. Run the application

streamlit run app.py
